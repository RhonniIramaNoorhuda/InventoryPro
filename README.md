# InventoryPro - Sistem Manajemen Gudang & Stok Barang 📦

InventoryPro adalah aplikasi manajemen inventaris modern yang dirancang untuk memudahkan admin atau pengelola gudang (khususnya bahan makanan restoran) dalam melacak ketersediaan stok, memantau riwayat transaksi, dan mengelola data barang secara *real-time*.

🌍 **Live Web Preview:** [https://inventorypro-40935.web.app](https://inventorypro-40935.web.app)

## ✨ Fitur Utama
* **Dashboard Statistik:** Pemantauan total bahan, total stok, jumlah kategori, dan peringatan stok menipis secara *real-time*.
* **Manajemen Bahan (CRUD):** Penambahan, pengeditan, dan penghapusan bahan baku dengan detail kuantitas serta pilihan satuan baku (Kg, Gram, Liter, dll).
* **Riwayat Aksi Presisi:** Pencatatan setiap aktivitas (Tambah, Edit, Hapus) secara otomatis yang dilengkapi dengan *timestamp* dan detail jumlah beserta satuannya.
* **Pencarian Cepat:** Fitur *search bar* yang dioptimalkan untuk mencari bahan berdasarkan nama atau kategori.

## 🛠️ Tech Stack
* **Frontend:** Flutter (Web & Mobile Support)
* **Backend & Database:** Firebase Firestore (NoSQL Real-time Database)
* **Authentication:** Firebase Auth
* **State Management:** Provider
